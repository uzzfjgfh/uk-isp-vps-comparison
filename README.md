## 先把概念理顺：英国住宅IP VPS到底是个什么东西

很多人把"英国VPS"和"英国住宅IP VPS"混为一谈，买回去才发现根本不是一回事。两者的差别，核心在IP属性，而不是机房位置。

普通英国VPS，机房在伦敦没错，但分配的IP段属于数据中心ASN（Autonomous System Number），你查ipinfo.io或者scamalytics，type一栏写的是"hosting"或"datacenter"。这种IP做建站、跑脚本、挂梯子都没问题，但凡涉及到"平台识别你是否本地真实用户"的场景，就会露馅。

英国住宅IP VPS则不同，它的IP来自英国本土宽带运营商的真实住宅段，ASN注册信息指向ISP而非机房，type显示residential或ISP。一些更讲究的方案会做成"双ISP"——也就是上游和下游都是ISP属性，纯净度更高，欺诈评分（fraud score）接近0。CstoneCloud主推的就是这种双ISP路线。
